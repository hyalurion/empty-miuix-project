# Example Project

A native Android application built with Jetpack Compose and the Miuix design system, providing a clean starting point with settings management, in-app licenses view, and a built-in markdown rendering engine.

## Project Overview

This project is a general-purpose Android app skeleton that retains the framework, markdown rendering engine, theme/language management, and update-checking infrastructure needed by most Miuix-based applications. Gift-specific features and the legacy Go backend have been removed, leaving a lean base you can extend for your own use case.

- **Android App**: Native Android application built with Jetpack Compose and Miuix KMP
- **Package**: `com.hyalurion.exampleproject`

## Features

### Android Application
- Jetpack Compose UI with Miuix design system
- Single-tab navigation with a floating bottom bar (Settings)
- Settings screen with theme switching (Light/Dark/System) and language selection
- In-app Licenses screen auto-generated from `app/licenses/licenses.json` at build time
- Automatic update checking and APK download
- Multi-language support (English, Chinese Simplified/Traditional, Japanese)
- Built-in markdown rendering engine (parser + renderer + formula support)
- Responsive layout for different screen sizes

  - Kotlinx Serialization — JSON serialization
  - Miuix KMP — Design components (ui, preference, icons, blur)

## Build-time License Generation

The in-app Licenses screen reads `com.hyalurion.exampleproject.data.LicensesData`, which is generated by the `generateLicenseInfo` Gradle task from `app/licenses/licenses.json` (and the referenced `.txt` files). Editing those config files changes what the screen displays at build time, so the license list no longer needs to be hand-maintained inside Kotlin source.

The generated file is emitted to `build/generated/license/kotlin/com/hyalurion/exampleproject/data/LicensesData.kt` and wired into the `main` source set via `kotlin.srcDir`.

## Installation

### Prerequisites
- Android Studio
- JDK 25 or higher
- Android SDK with `compileSdk` 37

### Android App Setup

1. Open the `android` directory in Android Studio
2. Wait for Gradle sync to complete
3. Build and run the app on an emulator or physical device

## Multi-Language Support

The project supports four languages:
- English (en)
- Chinese Simplified (zh-CN)
- Chinese Traditional (zh-TW)
- Japanese (ja)

Language strings are defined in `res/values/` directories:
- `values/` — Default (English)
- `values-zh-rCN/` — Chinese Simplified
- `values-zh-rTW/` — Chinese Traditional
- `values-ja/` — Japanese

## Version Management

The Android app uses a timestamp-based versioning scheme:
- Format: `1.YYYYMMDD.HHMM`
- Example: `1.20260826.1430`

`versionCode` is derived from `System.currentTimeMillis() / 1000`, and `versionName` is `1.<datePart>.<buildNumber>` where `buildNumber` defaults to the build time but can be overridden via the `buildNumber` Gradle project property.

## Configuration

### API Base URL

The app's API base URL is configured in [UpdateChecker.kt](android/app/src/main/java/com/hyalurion/exampleproject/data/UpdateChecker.kt). Update the `apiBaseUrl` variable to point at your own update server if you intend to use the update-check feature.

### Signing

Release builds are signed using a keystore described in `android/keystore.properties` (not checked in). Provide `STORE_FILE`, `STORE_PASSWORD`, `KEY_ALIAS`, and `KEY_PASSWORD` entries to enable signed release builds.

## Building

### Android APK

To build a release APK:

1. Open the project in Android Studio
2. Select **Build > Generate Signed Bundle / APK**
3. Follow the signing wizard
4. The APK will be generated in `app/release/`

Or from the command line:

```bash
cd android
./gradlew assembleRelease
```
